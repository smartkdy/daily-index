# Daily Index

이 사이트는 **https://dailyindex.pro** 로 이전했어요.

이 저장소에는 옛 주소(`smartkdy.github.io/daily-index/`) 방문자를 새 주소로 보내는 리다이렉트 파일만 남아 있어요.
- `index.html`: 첫 화면 → https://dailyindex.pro/
- `404.html`: 지난 리포트 주소(`/daily-index/reports/YYYY-MM-DD.html`) → https://dailyindex.pro/reports/YYYY-MM-DD
